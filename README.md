## Why it's not just a list

- **Search** across every question, answer and code sample
- **Filter** by topic and by difficulty level
- **Quiz mode** blurs the answers so you can practise active recall
- **Mark** each question as known or flagged, saved in your browser
- **Progress** tracked overall and per topic
- **Deep links** to any individual question
- **Keyboard shortcuts** — `/` search, `j`/`k` move, `g` mark known, `f` flag
- Works offline, prints cleanly, light and dark themes

## Running it locally

It's a single self-contained HTML file. Clone and open `index.html`, or:

```bash
python3 -m http.server 8000
```

No build step, no dependencies, no analytics.

## Contributing

Found a question that should be here, or an answer that's wrong or incomplete? Open an issue or a pull request. All the content lives in the `DATA` array inside `index.html`.
